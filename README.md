Global Flood Archive – Data Cleaning Using Microsoft Excel
About the Project
This project involved cleaning a global flood dataset using Microsoft Excel. The dataset contains flood records from around the world between 1985 and 2021.

The data had some issues, such as empty columns, misspelt country names and inconsistent text. The aim was to clean the data and make it ready for analysis.

Tools Used
Microsoft Excel 

What I Did
Checked for missing values.
Removed columns that were mostly empty.
Corrected misspelt country names.
Grouped similar flood causes into clear categories.
Fixed inconsistent spellings.
Removed incomplete records.
Formatted dates and numbers correctly.

Result

After cleaning, the dataset had no missing values and the information was consistent and easier to work with.

What I Learned

This project helped me understand why data cleaning is important before analysis. I gained more practice in spotting errors and preparing data that gives accurate results.
